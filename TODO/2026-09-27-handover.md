## Method, because these mattered

- **A hidden browser tab loads no media.** Chrome defers media in a tab that
  is not visible, so a test tab stalls at `readyState` 0 with no error.
  `document.visibilityState` says which. A hidden tab is fine for pages,
  options panels and sessions; not for playback events or anything saved as
  playback moves.
- **Look at the network with the page's own resource timing** when the
  extension's network reader sees nothing: pending requests do not appear
  until they finish.
- **Prove a leak with a probe, not a log.** The transcode-slot leak was
  settled by creating a transcode from a script (test account) right after
  the browser action: refused means held, created means free. The probe
  script lived in the session scratchpad and is gone; it is 20 lines on
  core's `MachaPlaybackResolver` (create at `maxHeight 480`, then stop).
- **Chrome caches a playing page on navigation** (`pagehide` with
  `persisted: true`), which is what hid the page-exit close.
- **Test failures under load:** the Server session's builds push load past
  300 and the Import-page tests hit vitest's 5 s limit. Save the run's output
  to a file so a failure's name is not lost, rerun alone, and record the
  load. One failure on the 27th was never named because it scrolled away.
- **`invalid_state` and similar codes mean different things on different
  routes.** Word them where the route is known, not globally.
- **Mutation-check every new test**; done throughout.
