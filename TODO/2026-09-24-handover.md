## Method, because these cost time today

- **Check the suite's result before committing.** A test committed red is
  the day's worst slip.
- **Never call a failure flaky.** Loop the suite with a JSON reporter per
  run and keep the failing names; that found the paging test in minutes.
- **A background test loop starves the browser**: page evaluations time out
  while it runs. Do not measure pages during one.
- **zsh does not split `$var` into words**: list files explicitly, and quote
  `--include='*.ts'` for grep.
- **Core rebuilds under you.** Its dist changed several times an hour
  today; typecheck against it before trusting a green, and restart Vite.
- **Ask core for anything shared** (routes, orderings, vocabularies), and
  now word all viewer text here, never in core.
- **Measure before styling**: the column widths, the confirm prompt, the
  result column and the header overflow were all found by measuring the
  live page, not by reading CSS.
