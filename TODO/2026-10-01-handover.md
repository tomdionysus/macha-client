## Method, because these mattered

- **Prove the mechanism before proposing a fix.** The Direct Play bar was
  settled by reading Chromium's source and then a live capture (two ranges
  growing for one playhead), before any server change was asked for.
- **Read the job back, not the request.** Start paused's confirmation reads
  the job the server answers; the live check then found the list still
  reading state alone, which is how the held-torrent bug was caught.
- **The in-page log survives only until a reload.** To read full records,
  import core's module in the page:
  `await import('/@fs/Users/tom/devroot/macha-ts/dist/diagnostics/ClientLog.js')`
  then `clientDiagnosticsConsole().snapshot()`. A reload clears it.
- **Browser tool limits.** A JavaScript call over ~45 s fails; sample in
  shorter calls. Element refs go stale when the page polls; click by
  position or re-find. A hidden tab loads no media (check
  `document.visibilityState`). Tom may close the tab group at any time.
- **Shell traps here.** macOS has no `timeout` (use `perl -e 'alarm N; exec
  @ARGV'`); in zsh an argument starting `=` is expanded (`echo =====`
  fails; quote it).
- **The permission check can be down.** On 2026-09-28 the auto-mode
  classifier gave no verdict for a whole turn; reading files still worked.
  Ten misses in a row end the turn, so stop spending them.
- **Mutation-check every new test**, and when a mutation is not caught,
  take it as a missing case (it found the omitted-audio case and the
  first-sample traffic case).
