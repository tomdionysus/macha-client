## Method, because these mattered

- **A command chain can commit what it never tested.** `npm run
  typecheck && vitest ...; vite build && git commit` committed after a
  failed typecheck skipped the suite. Gate the commit on the suite's own
  exit status.
- **Prove a checker both ways before trusting it.** The comment-only
  checker passed a `//` edit and caught a code edit, but treated every
  JSDoc edit as code; the agents found it. Its fixed form is reproducible:
  tokens of each file with comments removed, JSDoc nodes skipped.
- **The browser's resource timing list fills up** (250 entries) on a page
  that polls: a request missing from it was not missing from the network.
  Intercept `fetch` instead, and block a write locally to test a click
  without side effects.
- **The in-page log rolls over quickly**; read it straight after the event.
- **MusicBrainz is paced at one request a second on the server**, behind
  one editor lock: send provider picture requests one at a time.
- **On a loaded machine, run the suite on its own and read its exit
  status.** With the load near 600, a chained verification ran out of its
  time limit and logged nothing for the suite; run separately, it passed.
- **Look before calling a fault current**: FI-1's conflicts had stopped
  when this handover was written; the journal said so.
